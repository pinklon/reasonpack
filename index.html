CURRENT

What it does today

Acquire. Normalize. Transcribe. Inventory. Verify. No imaginary feature inflation.

Acquire

  • YouTube-only URL allowlist
  • Metadata inspection
  • Media + caption acquisition
  • No playlist expansion

Normalize

  • H.264/AAC video
  • AAC audio
  • ffprobe metadata
  • Captions preserved when used

Prove

  • Transcript provenance
  • Manifest bytes + SHA-256
  • Checksum inventory
  • Closed-pack verification
ARCHITECTURE

Small core. Explicit dependencies.

Useful without SharePlane, Codex, Claude, Copilot, GitHub, Drive, or any cloud API key.

QUALITY

What good looks like

A recipient can understand it, install it, verify it, challenge it, and extend it without reconstructing the author's intent from chat history.

STRATEGIC VISION

Capture once. Reason many times.

The strategic move is not “download videos.” It is turning useful external information into durable context that survives the session, model, and provider.

Current

  • Strict YouTube URL gate
  • Metadata inspection
  • Media acquisition
  • H.264/AAC normalization
  • Audio extraction
  • Captions-first transcript
  • Optional local Whisper
  • ffprobe metadata
  • Manifest + byte counts
  • SHA-256 checksum inventory
  • Closed-pack verification
  • Doctor / inspect / self-test
  • One-command yt URL
  • No telemetry / auto-upload
