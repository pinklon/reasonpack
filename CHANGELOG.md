# Reference Kit Changelog

## v1.1 — documentation hardening

Runtime behavior is intentionally unchanged from the v1.0 reference distribution.

Changed:

- expanded architecture into component, contract, boundary and failure semantics;
- expanded PRD with goals, non-goals, numbered requirements, acceptance, risks and open questions;
- expanded product feature contract with CURRENT / NEXT / NOT YET behavior;
- expanded installation, support, operating and troubleshooting guidance;
- expanded success measures with proposed-vs-observed metric semantics;
- expanded security/rights boundary;
- added package contract;
- added support matrix;
- added operating model;
- added developer guide;
- added design decisions/tradeoffs;
- added quick feature-posture reference;
- strengthened root navigation and handoff philosophy.

The purpose of v1.1 is to demonstrate that a good engineering handoff preserves enough decision context to support independent use and extension without turning every document into a novel.

## v1.0 — initial professional reference distribution

- ReasonPack reference runtime derived from active upstream 1.0.0 behavior;
- macOS, Linux and Windows/WSL installers;
- product tour, diagrams and vision poster;
- synthetic pack fixture and package tests;
- initial architecture/PRD/vision/user documentation.
