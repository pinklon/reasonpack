# Changelog

## 1.0.1 - 2026-10-03

- First standalone public repository release.
- Preserves the qualified YouTube-only acquisition and closed-manifest verification core.
- Adds deterministic local `whisper-cli` discovery while preserving explicit environment overrides.
- Adds a neutral install path, CI contract checks, public documentation, and Apache-2.0 licensing.

## 1.0.0 - 2026-09-07

- Initial qualified ReasonPack implementation.
- Added `doctor`, `inspect`, `build`, `verify`, and `self-test`.
- Added YouTube host allowlisting, source captions, optional local Whisper fallback, manifests, SHA-256 closure, and rejection of untracked pack files.
